| Nhiệm vụ | File cần tạo |

| 2 | DemoDataFactory.java |
| 9 | ChartHelper.java |

DemoDataFactory tạo dữ liệu mẫu dựa trên model và API nhóm đã thống nhất; lịch sử và số dư cần khớp nhau. ChartHelper tạo/cập nhật hai biểu đồ JFreeChart từ dữ liệu StatisticsService; phối hợp cấu hình thư viện với người 1.

Tạo file bằng New → Class trên nhánh riêng. Các lớp trên chưa được triển khai.

Chi tiết BONUS: xem mục Công việc BONUS và docs/BONUS.md ở README gốc. Công việc mới đang chờ triển khai.
