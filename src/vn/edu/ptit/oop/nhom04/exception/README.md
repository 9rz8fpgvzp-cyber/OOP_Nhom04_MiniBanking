# Package exception

Package Java: `vn.edu.ptit.oop.nhom04.exception`.

| Nhiệm vụ | File cần tạo |
| --- | --- |
| 3 | InsufficientFundsException.java, WithdrawalLimitExceededException.java |
| 4 | AccountNotMaturedException.java |
| 5 | InvalidAmountException.java, AccountNotFoundException.java |
| 8 — bonus | AccountLockedException.java |

Mỗi exception mô tả một lỗi nghiệp vụ. Người phụ trách thống nhất constructor, thông điệp và checked/unchecked với các thành viên gọi nó. Tạo các exception dùng chung sớm; không tạo các bản cùng tên ở package khác. GUI chịu trách nhiệm hiển thị thông báo.

Các file trong bảng là công việc cần làm, chưa được triển khai.

Chi tiết BONUS: xem mục Công việc BONUS và docs/BONUS.md ở README gốc. Công việc mới đang chờ triển khai.
