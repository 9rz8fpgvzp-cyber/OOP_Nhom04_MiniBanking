# Package ui.panels

Package Java: `vn.edu.ptit.oop.nhom04.ui.panels`.

**Nhiệm vụ 8:** tạo AccountDetailsPanel.java, kế thừa JPanel, hiển thị chủ sở hữu, loại tài khoản, số dư và quy tắc/giới hạn tương ứng. Cùng nhiệm vụ này, AccountListRenderer.java nằm ở package ui (thư mục cha).

Thống nhất cách truyền/cập nhật Account với người 1; panel chỉ hiển thị, không tự thay đổi số dư. Tạo lớp trên nhánh feat/account-ui. Chưa có mã triển khai cho panel.
