# Package service

Package Java: `vn.edu.ptit.oop.nhom04.service`.

| Nhiệm vụ | File cần tạo |
| --- | --- |
| 4 | MonthlyInterestService.java |
| 5 | Bank.java, TransferService.java, BankingOperations.java (interface) |
| 9 | StatisticsService.java |
| 8 — bonus | PinService.java: xác thực theo tài khoản, đếm lần sai, khóa sau 3 lần sai liên tiếp |

Bank quản lý tài khoản và điều phối thao tác; TransferService bảo đảm chuyển khoản toàn vẹn; MonthlyInterestService xử lý kỳ lãi; StatisticsService tổng hợp dữ liệu lịch sử. Người 5 chốt API sớm cho GUI và các thành viên phụ thuộc.

Tạo file trên nhánh của người phụ trách, không mở JOptionPane trong service. Các file trong bảng chưa được triển khai.
